게임 소개 2D 도트 자동 전투 로그라이크

자동 전투

방향만 정하면 전투는 알아서. 스킬 순서와 장비를 고르는 게 실력이다.

폭발하는 축복

출정과 보스 처치마다 셋 중 하나. 경험치 7배, 공격력 8배 같은 한 판의 운.

잃지 않는 성장

세션이 끝나도 골드·유물·도감은 남는다. 강화가 쌓일수록 더 깊이 간다.

맵 10개, Lv 300,000

숲에서 세계의 끝까지. 몬스터 200여 종, 유물 50종, 맵마다 다른 칩튠 음악.

출정

매번 Lv 1 에서 시작해 축복 하나를 고른다.

탐험·전투

걸을수록 몬스터를 만나고 레벨이 오른다. 깊은 구역일수록 위험하다.

보스

구역 끝의 보스를 쓰러뜨리면 다음 맵이 열린다.

귀환·강화

기력이 다하거나 쓰러져도 전리품은 남는다. 로비에서 영구 강화.

축복 세션 동안만, 최대 5레벨

거인의 힘불굴의 육체철벽질풍현자의 축복황금 손 끝없는 길사냥꾼의 눈시간 가속행운의 별승자의 만찬불사조

맵 왼쪽 입구에서 오른쪽 보스까지

다운로드

  • 설치형: 설치 후 시작 메뉴에서 실행. 포터블: 받은 파일을 바로 실행.
  • Windows 에서 "PC 보호" 창이 뜨면 추가 정보 → 실행을 누른다 (서명되지 않은 테스트 빌드).
  • Android 는 APK 를 받아 설치한다. 처음이면 "출처를 알 수 없는 앱 설치"를 허용해야 한다.
  • 세이브는 기기에 저장된다. 새 버전을 설치해도 이어서 할 수 있다.
